# 게임 소개

# DUNGEON DECK은 공격, 방어, 회복을 선택하며 던전을 공략하는 턴제 전투 RPG이다. 플레이어는 J키로 적을 공격하고, 적의 반격에 맞춰 K키로 방어한다. 일반 고블린을 처치하면 포션을 획득하며, L키로 포션을 사용해 체력을 회복할 수 있다. 두 번의 일반 전투를 통과한 뒤 마지막 고블린 주술사 보스를 처치하면 게임에서 승리한다.

# 게임 기본 정보

# 게임 제목: DUNGEON DECK

# 장르: 턴제 전투 RPG

# 플레이 방식: 싱글 플레이

# 핵심 목표: 3개 Stage를 진행하고 최종 보스 고블린 주술사 처치

# 시작 능력치: HP 50

# 플레이어 공격력: 8

# 방어 성공 확률: 60%

# 시작 포션 수량: 0개

# 포션 회복량: 사용마다 HP 10\~20 무작위 회복  

# 핵심 재미

# 적을 공격한 뒤 반격이 들어오기 전에 방어를 선택한다.

# 방어에 성공하면 피해를 전부 막지만, 실패하면 적의 공격력만큼 피해를 받는다.

# 일반 몬스터를 처치해 포션을 모으고 필요한 시점에 사용한다.

# 포션의 회복량이 무작위로 결정되어 현재 HP와 남은 포션 수를 고려해야 한다.

# 마지막에는 일반 몬스터보다 체력과 공격력이 높은 보스와 전투한다.  

# 게임 진행 흐름

# 메인 메뉴에서 GAME START를 선택한다.

# 플레이어 HP 50, 포션 0개로 첫 번째 전투를 시작한다.

# J키를 누르면 적에게 8 Damage를 준다.

# 적이 살아 있으면 반격을 준비한다.

# 반격이 들어오기 전에 K키를 누르면 방어를 시도한다.

# 일반 몬스터를 처치하면 포션 1\~2개를 자동으로 획득하고 다음 Stage로 이동한다.

# 자기 차례에 L키를 누르면 포션 1개를 사용해 체력을 회복한다.

# Stage 3에서 고블린 주술사 보스와 전투한다.

# 플레이어 HP가 0이 되면 패배하고, 보스를 처치하면 승리한다.

# 결과 화면에서 RETRY 또는 MAIN MENU를 선택한다.  

# 포션 규칙

# 포션은 0개로 시작한다.

# 일반 몬스터를 처치할 때마다 포션 1\~2개를 무작위로 획득한다.

# 획득한 포션은 다음 Stage로 넘어가도 유지된다.

# 화면 아래쪽에 포션 이미지와 현재 보유 개수를 표시한다.

# 자기 차례에 L키를 누르면 포션 1개를 사용한다.

# 사용할 때마다 HP 10\~20을 무작위로 회복한다.

# 회복 후 HP는 최대 HP 50을 넘을 수 없다.

# HP가 가득 찼거나 포션이 없으면 사용할 수 없으며, 포션도 소비되지 않는다.

# 적의 반격 준비 중이나 피격·회복 연출 중에는 포션을 사용할 수 없다.

# 포션 사용 시 치유 상태의 플레이어 초상화와 힐 효과음을 출력한다.

# 회복이 끝나면 다시 플레이어가 행동할 수 있으며, 포션 사용으로 적의 반격이 발생하지 않는다.

# 다시하기를 선택하면 포션 수량도 0개로 초기화된다.  

# 전투 규칙

# 플레이어는 J키로 적에게 8 Damage를 준다.

# 적이 살아 있으면 약 1.1초 동안 반격을 준비한 뒤 공격한다.

# 플레이어는 반격이 들어오기 전에 K키로 방어를 시도할 수 있다.

# 방어 성공 확률은 60%이며, 성공하면 피해를 받지 않는다.

# 방어에 실패하거나 방어하지 않으면 적의 공격력만큼 HP가 감소한다.

# 한 번의 반격에는 방어를 한 번만 시도할 수 있다.

# 자기 차례에 K키만 누르면 공격 없이 방어를 준비하고 적의 반격을 받는다.

# 공격과 방어를 연속 입력해도 진행 중인 행동이 중복 실행되지 않는다.

# 적의 HP가 0이 되면 해당 전투에서 승리하며, 처치된 적은 반격하지 않는다.

# 플레이어의 HP가 0이 되면 게임에서 패배한다.

# 일반 전투를 통과해도 플레이어의 남은 HP는 유지된다.

# 다시하기를 선택하면 HP 50으로 첫 번째 전투부터 시작한다.
