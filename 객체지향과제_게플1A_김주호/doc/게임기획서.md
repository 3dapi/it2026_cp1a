\# Aim Click 게임 기획서



\## 1. 게임 개요



\### 게임명



Aim Click



\### 장르



2D 에임 연습 / 반응속도 게임



\### 게임 설명



화면의 임의 위치에 생성되는 타겟을 마우스로 클릭하여 점수를 획득하는 게임이다.



플레이어는 제한 시간 동안 최대한 많은 타겟을 클릭하여 높은 점수를 획득하는 것을 목표로 한다.



\---



\## 2. 게임 진행



게임이 시작되면 화면의 임의 위치에 원형 타겟이 생성된다.



생성된 타겟을 마우스로 클릭하면 타겟이 제거되고 점수가 증가한다.



각 타겟에는 제한 시간이 존재하며, 생성된 이후 일정 시간이 지나도록 클릭되지 않은 타겟은 자동으로 사라진다.



사라진 타겟은 점수를 증가시키지 않는다.



게임 제한 시간이 종료되면 최종 점수를 표시하고 게임을 종료한다.



\---



\## 3. 조작 방법



| 입력      | 기능    |

| ------- | ----- |

| 마우스 이동  | 조준    |

| 마우스 좌클릭 | 타겟 클릭 |

| ESC     | 게임 종료 |



\---



\## 4. 타겟 시스템



타겟은 화면 내부의 임의 위치에 생성된다.



각 타겟은 다음 정보를 가진다.



\* 화면상의 위치

\* 타겟 크기

\* 생성 시간

\* 유지 시간

\* 활성화 여부



타겟을 클릭하면 즉시 제거된다.



타겟이 생성된 후 지정된 유지 시간이 지나면 자동으로 제거된다.



새로운 타겟은 일정한 시간 간격으로 계속 생성된다.



\---



\## 5. 점수 시스템



타겟을 정상적으로 클릭하면 점수를 획득한다.



\* 타겟 명중: +100점

\* 타겟을 클릭하지 못하고 사라짐: 점수 변화 없음



게임 종료 시 플레이어가 획득한 최종 점수를 화면에 표시한다.



\---



\## 6. 게임 UI



게임 화면에는 다음 정보를 표시한다.



\* 현재 점수

\* 남은 게임 시간

\* 생성된 타겟



게임이 종료되면 최종 점수를 표시한다.

\## 8. 주요 구현 기능



\### 마우스 입력



마우스의 현재 위치와 좌클릭 입력을 확인한다.



\### 타겟 생성



화면 내부의 임의 위치를 계산하여 타겟을 생성한다.



\### 클릭 판정



마우스를 클릭한 위치가 타겟 영역 내부인지 확인한다.



\### 타겟 생명주기



각 타겟의 생성 시간을 저장하고 지정된 시간이 지나면 자동으로 제거한다.



\### 점수 관리



타겟 클릭 성공 여부에 따라 현재 점수를 관리한다.



\### 게임 시간 관리



게임 시작 이후 경과 시간을 계산하고 제한 시간이 지나면 게임을 종료한다.



\---



\## 9. 개발 목표



API 환경에서 게임의 기본적인 입력, 출력, 시간 및 오브젝트 관리 구조를 직접 구현하는 것을 목표로 한다.



특히 다음 기능을 중점적으로 구현한다.



\* 게임 루프

\* 마우스 입력

\* 좌표 처리

\* 타겟 생성 및 삭제

\* 클릭 충돌 판정

\* 오브젝트 생명주기 관리

\* 점수 시스템

\* 게임 시간 관리



추가적으로 기본 기능 구현이 완료된 경우 타겟의 크기, 생성 속도, 유지 시간 등을 조절하여 게임의 난이도가 점차 상승하도록 구현한다.
