# 1인용 보드게임 기획서

## 1. 게임 제목
**다이스 헌터**

## 2. 게임 장르
1인용 주사위 전략 보드게임

## 3. 게임 인원
1명

## 4. 플레이 시간
약 10~15분

## 5. 게임 목표
플레이어는 주사위 5개를 굴려 다양한 조합을 만들고 점수를 획득한다.

총 10라운드 동안 최대한 높은 점수를 얻는 것이 목표이며, 최종 점수에 따라 게임의 결과가 결정된다.

## 6. 준비물
- 6면체 주사위 5개
- 점수 기록지 1장
- 필기구 1개

## 7. 게임 진행 방법

게임은 총 10라운드로 진행된다.

각 라운드는 다음과 같은 순서로 진행한다.

1. 주사위 5개를 모두 굴린다.
2. 원하는 주사위를 선택하여 유지할 수 있다.
3. 유지하지 않은 주사위만 다시 굴린다.
4. 한 라운드에 주사위는 최대 3번까지 굴릴 수 있다.
5. 주사위를 모두 굴린 후 원하는 점수 항목 하나를 선택한다.
6. 해당 항목의 조건에 맞는 점수를 기록한다.
7. 한 번 사용한 점수 항목은 다시 사용할 수 없다.
8. 10개의 점수 항목을 모두 사용하면 게임이 종료된다.

## 8. 점수 규칙

| 점수 항목 | 조건 | 점수 |
|---|---|---|
| 원 | 숫자 1 주사위 | 나온 1의 합 |
| 투 | 숫자 2 주사위 | 나온 2의 합 |
| 쓰리 | 숫자 3 주사위 | 나온 3의 합 |
| 포 | 숫자 4 주사위 | 나온 4의 합 |
| 트리플 | 같은 숫자가 3개 이상 | 주사위 5개의 합 |
| 포카드 | 같은 숫자가 4개 이상 | 25점 |
| 풀하우스 | 같은 숫자 3개와 같은 숫자 2개 | 30점 |
| 스트레이트 | 1,2,3,4,5 또는 2,3,4,5,6 | 40점 |
| 야추 | 같은 숫자가 5개 | 50점 |
| 찬스 | 아무 조합 | 주사위 5개의 합 |

조건을 만족하지 못한 점수 항목을 선택하면 해당 항목에는 0점을 기록한다.

## 9. 게임 종료

모든 점수 항목을 사용하면 게임이 종료된다.

각 항목에서 획득한 점수를 모두 더하여 최종 점수를 계산한다.

## 10. 결과 판정

| 최종 점수 | 결과 |
|---|---|
| 0~149점 | 실패 |
| 150~199점 | 클리어 |
| 200~249점 | 우수 |
| 250점 이상 | 최고 기록 |

플레이어는 게임을 반복하며 자신의 최고 기록을 갱신하는 것을 목표로 한다.

## 11. 게임의 특징

### 간단한 규칙
주사위를 굴리고 원하는 주사위를 남기는 방식이기 때문에 처음 플레이하는 사람도 쉽게 이해할 수 있다.

### 선택 요소
어떤 주사위를 남길지, 어떤 점수 항목을 사용할지 플레이어가 직접 판단해야 한다.

### 운과 전략
주사위의 결과는 운에 따라 결정되지만, 주사위를 다시 굴릴지 유지할지 선택하는 과정에서 전략적인 플레이가 가능하다.

### 반복 플레이
매 게임마다 주사위 결과가 달라지기 때문에 같은 규칙으로도 다른 상황이 발생하며, 자신의 최고 점수를 갱신하는 재미가 있다.

## 12. 핵심 재미 요소
게임의 핵심 재미는 좋은 주사위 조합을 만들기 위해 주사위를 선택하고 다시 굴리는 과정에서 발생한다.

안전하게 현재 점수를 확보할지, 더 높은 점수를 얻기 위해 다시 주사위를 굴릴지 고민하게 만들며, 높은 점수의 조합을 성공했을 때 성취감을 느낄 수 있도록 구성한다.

## 13. 게임 흐름

게임 시작

↓

↓  
나머지 주사위 다시 굴리기  
↓

↓

↓

↓  
게임 종료

## 14. 기대 효과
간단한 준비물만으로 플레이할 수 있고 규칙이 복잡하지 않아 접근성이 높다.

또한 운에만 의존하지 않고 플레이어가 직접 주사위를 선택하고 점수 항목을 결정해야 하기 때문에 간단한 전략 게임으로 즐길 수 있다.
