# 게임 제작 과제 기획서

* 게임 제목: Stone Age
* 장르: 생존 액션
* 예상 플레이 시간: 5분 이하

# 1. 게임 개요

## 1-1. 게임 소개

* 제한된 전장 안에서 계속해서 생성되는 적을 처치하며 제한 시간 동안 생존하는 게임

## 1-2. 게임 목표

* 제한 시간 동안 생존
* 다가오는 적을 공격하여 처치
* 적의 공격과 충돌을 피하며 최대한 많은 적 처치

## 1-3. 게임 특징

* 제한된 사각형 전장
* WASD를 이용한 플레이어 이동
* 플레이어 이동 방향을 기준으로 하는 자동 근접 공격
* 일정 시간마다 적 생성
* 생성된 적이 플레이어를 추적
* 적과 충돌하면 플레이어 HP 감소
* 적 처치 시 처치 수 증가
* 제한 시간 종료 또는 플레이어 사망에 따라 게임 결과 결정

# 2. 게임 진행

## 2-1. 전체 게임 흐름

게임 시작 → 게임 플레이 → 적 생성 → 적 추적 및 전투 → 게임 오버 / 게임 클리어

## 2-2. 게임 진행 순서

1. 게임 시작
2. 플레이어 생성
3. 제한된 전장 안에서 이동
4. 일정 시간마다 적 생성
5. 적이 플레이어를 추적
6. 플레이어의 자동 근접 공격으로 적 처치
7. 적과 충돌하면 HP 감소
8. HP가 0이 되면 게임 오버
9. 제한 시간까지 생존하면 게임 클리어

### 시작 화면

* 게임 제목 표시
* 게임 시작 버튼
* 게임 종료 버튼

### 인게임 화면

* 플레이어와 적 표시
* 현재 남은 시간 표시
* 현재 처치한 적의 수 표시
* 현재 플레이어 HP 표시
* 플레이어의 공격 이펙트 표시

### 게임 결과 화면

* 게임 클리어 여부 표시
* 남은 시간, 총 처치한 적의 수, 남은 체력 표시
* 다시 시작 버튼
* 게임 종료 버튼

# 3. 조작 방법

## 3-1. 게임 플레이 조작

| 입력 | 기능       |
| -- | -------- |
| W  | 위로 이동    |
| A  | 왼쪽으로 이동  |
| S  | 아래로 이동   |
| D  | 오른쪽으로 이동 |

## 3-2. UI 조작

| 입력      | 기능    |

# 4. 플레이어

## 4-1. 플레이어 능력치

| 능력치   | 설명           |
| ----- | ------------ |
| HP    | 플레이어의 현재 체력  |
| 공격력   | 적에게 가하는 피해량  |
| 공격 범위 | 근접 공격의 판정 범위 |
| 공격 속도 | 공격 발생 간격     |

## 4-2. 플레이어 피격

* 적과 충돌하면 HP 감소
* 피격 후 짧은 시간 동안 무적 상태
* HP가 0이 되면 게임 오버

## 4-3. 플레이어 공격

* 플레이어의 이동 방향을 기준으로 근접 공격
* 일정한 공격 속도로 자동 공격
* 공격 범위 내의 적에게 피해
* 공격 시 공격 이펙트 표시

# 5. 적 시스템

## 5-1. 적

* 플레이어를 추적
* 플레이어보다 느린 이동 속도
* 일정 시간마다 새로운 적 생성
* 공격을 받아 HP가 0이 되면 처치
* 적이 처치될 경우 처치 수 증가

## 5-2. 적 생성

* 플레이어와 일정 거리 이상 떨어진 위치에서 생성
* 생성 위치는 무작위로 결정
* 일정 시간 간격으로 적 생성
* 적끼리 충돌할 경우 서로 밀려나도록 처리

# 6. 전장

## 6-1. 맵 구성

* 화면 전체를 사용하는 사각형 형태의 전장
* 플레이어는 전장 밖으로 이동할 수 없음

## 6-2. 전투 환경

* 제한된 공간에서 적이 지속적으로 생성
* 생성된 적은 플레이어를 추적
* 플레이어는 이동과 공격을 통해 적을 처치하며 생존

# 7. 게임 흐름도

게임 시작 화면
↓
게임 시작
↓
게임 플레이
↓
적 생성 및 추적
↓
플레이어 이동 및 자동 공격
↓
├─ 플레이어 HP = 0 → 게임 오버 → 결과 표시 → [다시 시작] / [메인 화면]
└─ 제한 시간 종료 → 게임 클리어 → 결과 표시 → [다시 시작] / [메인 화면]
