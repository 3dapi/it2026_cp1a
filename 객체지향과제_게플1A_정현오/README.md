## 게임 소개

광부를 좌우로 움직여 떨어지는 돌을 피하고, 돌에 충돌할 때까지 최대한 오래 버티며 높은 점수에 도전하는 게임입니다.

## 게임 흐름

```text
프로그램 실행
→ 타이틀 화면
→ 게임 시작
→ 돌을 피하며 점수 획득
→ 광부와 돌 충돌
→ 결과 화면
→ 다시 시작 또는 타이틀 화면으로 이동
```

타이틀 화면에서는 게임을 시작하거나 프로그램을 종료할 수 있습니다.

## 핵심 시스템

- 광부의 좌우 이동과 화면 경계 처리
- 무작위 위치에서 일정한 간격으로 돌 생성 및 낙하
- 광부와 돌의 충돌 시 게임 종료
- 땅에 도달한 돌 제거
- 게임 진행 중 1초마다 10점 획득
- 타이틀·플레이·결과 화면과 재시작

## 조작 방법

| 키 | 기능 |
|---|---|
