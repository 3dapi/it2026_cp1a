# 게임 기획서

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임명 | DEEPFALL |
| 장르 | 2D 생존 회피 게임 |
| 플랫폼 | Windows PC |
| 개발 환경 | C++, glc2d_lib, Visual Studio 2022 |
| 개발 인원 | 1명 |
| 개발 기간 | 4주 |
| 게임 목적 | 광산에서 떨어지는 돌을 피하며 최대한 오래 버티고 높은 점수를 획득한다. |

플레이어는 광산에 있는 광부를 조작한다. 광부는 화면 아래에서 좌우로 이동하며 위에서 떨어지는 돌을 피한다.

오래 버틸수록 점수가 증가하고, 돌과 한 번이라도 겹치면 게임이 종료된다. 결과 화면에서 최종 점수를 확인하고 다시 도전하거나 타이틀 화면으로 돌아갈 수 있다.

---

## 2. 핵심 플레이 방식

플레이어는 돌이 떨어지는 위치를 확인하고 안전한 위치로 이동한다.

```text
돌 생성
→ 낙하 위치 확인
→ 광부를 이동하여 회피
→ 1초마다 점수 증가
→ 다음 돌을 계속 회피
```

돌과 충돌할 때까지 위 과정을 반복한다. 떨어지는 돌을 보며 이동 방향과 타이밍을 판단하는 것이 핵심이다.

---

## 3. 조작 방법

| 입력 | 기능 |
|---|---|
| A / D | 캐릭터 좌우 이동 |
| W / S | UI 선택 항목 위아래 이동 |
| Space | 상호작용 — 선택한 UI 항목 실행 |

- A/D로 광부를 각각 왼쪽과 오른쪽으로 이동하며, 두 키를 동시에 입력하면 정지한다.
- 타이틀과 결과 화면에서는 W/S로 항목을 선택한다.
- Space 키로 선택한 UI 항목을 실행한다.

---

## 4. 기본 게임 규칙

| 항목 | 규칙 |
|---|---|
| 플레이 인원 | 1명 |
| 플레이 공간 | 광산 배경의 고정된 화면 |
| 이동 범위 | 화면 아래쪽 땅 위의 좌우 영역 |
| 목숨 | 1회 |
| 광부와 돌의 충돌 | 게임 종료 |
| 돌과 땅의 충돌 | 해당 돌 제거 |
| 제한 시간 | 없음 |
| 진행 방식 | 광부가 돌과 충돌할 때까지 진행 |
| 결과 기준 | 종료 시 획득한 최종 점수 |

광부는 땅 위의 일정한 높이에서 좌우로 이동하며, 화면 밖으로 나갈 수 없다. 화면의 왼쪽 또는 오른쪽 끝에 도달하면 해당 방향으로 더 이동하지 않는다.

별도의 스테이지 클리어 조건은 없다. 최대한 오래 생존하여 더 높은 점수를 획득하는 것이 목표이다.

## 5. 플레이어와 장애물의 행동

### 플레이어: 광부

- 게임 시작 시 화면 아래쪽 땅 위의 정해진 위치에 배치된다.
- A/D 입력에 따라 좌우로 이동한다.
- 돌이 떨어지는 위치에서 벗어나 생존한다.
- 돌과 충돌하면 사망한다.
- 사망 후 1.5초 뒤 결과 화면을 표시한다.

### 장애물: 돌

- 게임이 시작되면 0.6초마다 돌 한 개를 생성한다.
- 이전 돌이 떨어지는 동안에도 다음 돌을 생성하여 여러 돌이 동시에 화면에 존재할 수 있다.
- 돌은 화면 위쪽 바깥의 무작위 가로 위치에서 생성된다.
- 생성 위치는 돌이 화면 안으로 들어올 수 있는 범위로 제한한다.
- 생성된 돌은 수직 아래 방향으로 일정한 속도로 이동한다.
- 땅에 도달한 돌은 제거한다.
- 같은 종류의 돌을 여러 개 생성하여 사용한다.

### 충돌 처리

광부와 돌의 사각형 충돌 영역이 겹치면 충돌로 판정한다.

한 번 충돌하면 목숨을 잃고 게임이 종료된다.

돌이 땅에 도달한 경우에는 해당 돌을 제거한다.

## 6. 점수 규칙

게임이 진행되는 동안 완전히 지난 1초마다 10점씩 증가한다.

```text
점수 = 게임 진행 시간의 정수 부분 × 10
```

| 게임 진행 시간 | 점수 |
|---|---:|
| 5초 | 50점 |
| 12.8초 | 120점 |
| 30초 | 300점 |
| 60초 | 600점 |

- 타이틀 화면과 결과 화면에서는 점수가 증가하지 않는다.
- 돌을 피한 횟수에 따른 별도 점수는 없다.
- 광부가 돌과 충돌한 순간의 점수를 최종 점수로 확정한다.
- 새로운 게임에서는 점수를 처음부터 계산한다.

## 7. 게임 시작·종료·재시작 조건

### 게임 시작

- 프로그램을 실행하면 타이틀 화면을 표시한다.
- 타이틀 화면에는 게임 시작과 게임 종료 항목을 배치한다.
- 처음에는 게임 시작 항목을 선택한 상태로 표시한다.
- W/S로 항목을 선택하고 Space 키로 실행한다.
- 게임 시작 항목을 실행하면 플레이 화면으로 전환하여 게임을 시작한다.

### 게임 종료

- 광부와 돌이 충돌하면 진행 중인 게임을 종료한다.
- 게임 진행을 멈추고 최종 점수를 확정한다.
- 결과 화면으로 전환하여 확정된 기록을 표시한다.

### 다시 시작

- 결과 화면에는 다시 시작과 처음으로 항목을 배치한다.
- 처음에는 다시 시작 항목을 선택한 상태로 표시한다.
- W/S로 항목을 선택하고 Space 키로 실행한다.
- 다시 시작 항목을 실행하면 새로운 게임을 시작한다.

### 처음으로

- 결과 화면에서 처음으로 항목을 선택할 수 있다.
- W/S로 항목을 선택하고 Space 키로 실행한다.
- 처음으로 항목을 실행하면 타이틀 화면으로 이동한다.

### 프로그램 종료

타이틀 화면에서 게임 종료 버튼을 선택하고 Space 키를 누르면 프로그램을 종료한다.

---

## 8. 게임 진행 흐름

```text
프로그램 실행
      ↓
타이틀 화면
      ├─ 게임 종료 선택 → Space → 프로그램 종료
      │
      └─ 게임 시작 선택 → Space
                  ↓
              게임 플레이
              ├─ 광부 이동
              ├─ 돌 생성과 낙하
              ├─ 점수 증가
              └─ 돌과 광부·땅의 충돌 검사
                  ├─ 땅과 충돌 → 해당 돌 제거 후 플레이 계속
                  │
                  └─ 광부와 충돌
                          ↓
                       결과 화면
                          ├─ 다시 시작 선택 → Space → 게임 플레이
                          │
                          └─ 처음으로 선택 → Space → 타이틀 화면
```

## 12. 필요한 사운드 리소스 목록

| 사운드 | 수량 | 용도 |
|---|---:|---|
| 플레이 BGM | 1개 | 게임 플레이 중 반복 재생 |
| 충돌 효과음 | 1개 | 광부와 돌이 충돌했을 때 재생 |
| 버튼 클릭 효과음 | 1개 | Space 키로 버튼을 실행할 때 재생 |

게임을 시작하면 플레이 BGM을 재생한다. 광부와 돌이 충돌하면 충돌 효과음을 한 번 재생하며, 결과 화면으로 전환할 때 BGM을 정지한다.

다시 시작하면 플레이 BGM을 다시 재생한다.

버튼 클릭 효과음은 게임 시작, 게임 종료, 다시 시작, 처음으로 버튼에 공통으로 사용한다.

## 13. 제작 범위 및 구현 순서

| 단계 | 구현 내용 |
|---|---|
| 1단계 | 광부 출력, 좌우 이동과 화면 경계 처리 |
| 2단계 | 돌 생성과 낙하 |
| 3단계 | 광부·땅과 돌의 충돌 판정 및 땅에 도달한 돌 제거 |
| 4단계 | 광부와 돌의 충돌 시 게임 종료와 결과 화면 전환 |
| 5단계 | 점수, 타이틀 메뉴, 다시 시작과 처음으로 기능 |
| 6단계 | 이미지·사운드 적용과 전체 플레이 확인 |
