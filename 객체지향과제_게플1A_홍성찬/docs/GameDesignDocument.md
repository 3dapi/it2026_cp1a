# 게임 기획서

### 1. 게임 개요
***
+ 게임 제목: Block Runner
+ 게임 장르: 엔드리스 러너 (Endless runner)
+ 게임 설명: 플레이어는 점프를 통해 오른쪽에서 다가오는 여러 장애물들을 피하고, 생존 시간에 따라 점수를 획득한다.
+ 게임 목적: 점수 획득 및 최고점수 갱신
+ 화면 크기: 1024 x 600

### 2. 게임 시스템
***
#### 게임 플레이 방식
점프 키와 좌우 이동 키만으로 플레이어 캐릭터를 조종하는 간단한 조작 방식을 취한다.
플레이어는 다가오는 장애물들을 피하고, 장시간 생존하며 점수를 획득해야 한다.

#### 게임 조작 방법
+ 스페이스바: 시작 화면에서 게임을 시작한다.
+ 스페이스바: 플레이어 캐릭터가 지면이나 블록 위에 있을 때 점프시킨다.
+ A / D 키: 플레이어 캐릭터를 왼쪽 / 오른쪽으로 이동시킨다.
	+ 이동 방향에 따라 캐릭터 이미지가 앞모습 / 뒷모습으로 바뀐다.

#### 게임 규칙
***게임 시작 및 종료 조건***
+ 시작 조건: 시작 화면에서 스페이스바를 눌러 게임을 시작한다.
+ 종료 조건: 플레이어가 장애물에 충돌하거나 지정된 구역을 벗어났을 때, 게임이 종료된다. *(예정)*
	+ 현재는 장애물과의 충돌 여부만 기록하며, 게임 종료 및 결과 화면 전환은 아직 구현되지 않았다.

***점수 규칙***
+ 게임이 진행되는 동안 **1초마다 점수가 1점씩** 증가한다.

***난이도***
+ 난이도 상승은 **생존 시간에 비례한다.**
	+ 장애물의 이동 속도는 300에서 시작하여 **10초마다 10씩** 증가한다.
	+ 속도가 증가하면 이미 화면에 있는 장애물에도 즉시 적용된다.
+ 장애물은 **1~3초 사이의 랜덤한 간격**으로 생성된다.

#### 플레이어 행동
+ 플레이어는 화면 좌측(x: 200, y: 400)에서 시작한다.
+ 중력(2000)의 영향을 받아 떨어지며, 지면이나 블록 위에 서 있을 수 있다.
+ 점프를 통해 장애물을 피하며 점수를 획득한다.
+ 좌우 이동 속도는 200, 점프 힘은 1000이다.

#### 장애물 행동
+ 장애물의 Y좌표는 지면 위로 고정한다.
+ 화면 오른쪽 바깥(x: 1024)에서 생성되어 왼쪽(플레이어 방향)으로 움직인다.
+ 장애물의 왼쪽 면의 x좌표가 (-장애물 이미지 가로크기 - 5) 이하가 되면 비활성화된다.
+ 장애물 종류는 두 가지(블록, 두 칸 블록)이며, 생성될 때마다 랜덤으로 선택된다.
+ 장애물은 종류별로 5개씩 미리 만들어 두고, 비활성화된 장애물을 다시 활성화하여 재사용한다.
+ Obstacle 태그를 가진 오브젝트만 이동한다. (지면은 같은 Obstacle 클래스지만 움직이지 않는다.)

#### 충돌 감지
+ **AABB 알고리즘**: 플레이어와 장애물 및 지면 간 충돌을 감지한다.
	+ 겹친 영역의 가로 / 세로 길이를 비교하여 충돌 방향(상, 하, 좌, 우)을 판단한다.
	+ 충돌 방향에 따라 플레이어를 밀어내어 장애물이나 지면을 통과하지 않도록 한다.
	+ 충돌은 시작(Enter) / 유지(Stay) / 종료(Exit) 단계로 나누어 처리한다.
	+ 비활성화된 오브젝트는 충돌 검사에서 제외한다.

### 3. 게임 화면 구성
+ **시작 화면**
	+ 사막 배경 위에 게임 타이틀 이미지와 시작 안내 이미지를 표시한다.
+ **게임 플레이 화면**
	+ 플레이어는 게임 화면 좌측에 위치한다.
	+ 지면은 화면 하단(y: 500)에 위치한다.
	+ 화면 좌측 상단에 점수를 표기한다.
	+ 시간 표기 UI
+ **결과 화면**

### 4. 게임 진행 흐름
+ 게임의 전체적인 진행 흐름은 다음과 같다.
1. 시작 화면에서 스페이스바를 입력할 시, 게임 플레이 화면으로 전환되며 게임이 시작된다.
2. 1~3초 간격으로 장애물이 화면 오른쪽에서 생성되어 다가온다.
3. 장애물이 다가올 때, 플레이어는 점프키를 눌러 장애물을 피한다.

	3-1. 만약 플레이어가 장애물에 충돌하면 게임이 종료되고 결과 화면으로 전환된다.

	3-2. 플레이어가 장애물에 충돌하지 않으면 게임을 지속한다.
4. 1초마다 점수가 1점씩 증가한다.
5. 10초마다 장애물의 속도가 증가한다.

### 5. 주요 게임 객체 목록
| 클래스 | 설명 |
| --- | --- |
| GameObject | 모든 게임 객체의 부모 클래스 (위치, 충돌체, 태그, 활성화 여부) |
| Entity | 플레이어 캐릭터 (중력, 속도, 충돌 처리) |
| Obstacle | 장애물 및 지면 (태그가 Obstacle일 때만 이동) |
| Background | 배경 이미지 |
| Image | 타이틀, 안내 문구 등 UI 이미지 |
| GameManager | 객체 생성 / 업데이트 / 렌더링 및 충돌 검사 관리 |

+ 씬 구성: 시작(SceneGameStart), 플레이(SceneGamePlay), 결과(SceneGameResult)

### 6. 필요한 이미지 목록
