# Dungeon Escape 게임 기획서

- 작성자: 백경빈 (26311013)
- 최초 작성일: 2026.08.26 / 수정일: 2026.10.05
- 개발 환경: C++, Visual Studio 2022, glc2d

## 1. 게임 소개

공격·도구·도망을 선택하는 턴제 전투 게임이다. 숲, 폐허, 동굴을 지나 성채 보스를 처치하면 클리어한다. 일반 전투 3회와 보스전 1회로 구성하며, 실시간 이동이나 충돌 처리는 사용하지 않는다.

## 2. 진행 흐름

타이틀 → 게임 방법 → 숲 → 폐허 또는 동굴 선택 → 남은 지역 → 성채 보스 → 결과

- 일반 전투에서 승리하면 보상 하나를 선택한다. 도망에 성공하면 보상 없이 진행한다.
- 지역을 옮겨도 HP·도구·강화·점수는 유지되며 자동 회복은 없다.
- HP가 0이면 게임오버, 보스를 처치하면 게임 클리어다.
- 결과 화면에서 새 도전 시작 또는 타이틀로를 선택한다. 새 도전은 진행도와 능력치를 초기화한다.
- 중간 저장과 영구 강화는 없다.

## 3. 조작과 화면

| 키 | 기능 |
| --- | --- |
| 방향키 | 메뉴·지역·보상 선택, 설정 변경 |
| Enter | 선택 확정, 안내·전투 문구 진행 |
| Esc | 하위 메뉴 취소, 전투 일시정지, 안내·설정에서 타이틀 복귀 |
| A / B / Q | 전투 기본 메뉴에서 기본 공격 / 도망 / 회복약 |

타이틀에는 START / SETTING / EXIT를 표시한다. START 후 게임 방법에서 Enter를 누르면 시작한다. 타이틀의 Esc는 종료한다.

전투 화면에는 배경, 플레이어와 적, HP 숫자·막대, 공격력, 점수, 행동 메뉴를 표시한다. 지역 선택은 배경 미리보기 2개, 승리 보상은 카드 3개로 표현한다. 결과 화면에는 클리어·게임오버와 점수를 표시한다.

설정에서는 소리를 10%씩 조절하고 창 모드·전체 화면을 전환한다. 기본 화면은 1280×960이며, 글꼴은 Windows 맑은 고딕(메뉴 32px, 본문 24px)을 사용한다.

## 4. 전투 규칙

시작 상태는 **HP 100/100, 공격력 20, 회복약 3개, 고급 회복약 1개, 점수 0**이다.

플레이어가 행동한 뒤 적이 살아 있으면 반격한다. Enter로 행동 결과를 확인하며 턴을 진행한다. 적을 처치한 턴에는 반격을 받지 않는다. 메뉴 이동과 취소는 턴을 소비하지 않는다.

| 행동 | 효과 |
| --- | --- |
| 기본 공격 | 공격력만큼 피해, 명중률 100% |
| 강한 공격 | 공격력의 1.5배 피해, 명중률 75% |
| 흡수 공격 | 공격력의 0.5배 피해, 실제 준 피해의 절반 회복 |
| 회복약 / 고급 회복약 | HP 30 / 60 회복, 수량 1개와 턴 소비 |
| 도망 | 일반 전투에서 60% 확률로 성공, 실패하면 적이 반격 |

피해·회복 계산의 소수점은 버린다. HP는 0~최대 HP 범위로 제한하고, 회복 문구에는 실제 회복량을 표시한다. 물약이 없거나 HP가 가득 차면 도구와 턴을 소비하지 않는다. 보스전의 도망은 안내만 표시하며 턴을 소비하지 않는다.

## 5. 적과 보상

| 적 | 기본 HP | 기본 공격력 |
| --- | ---: | ---: |
| 숲의 야수 | 50 | 10 |
| 폐허의 수호자 | 70 | 12 |
| 동굴의 박쥐 | 40 | 14 |
| 성채 보스 | 200 | 18 |

일반 적은 두 번째 방문 지역에서 HP +10·공격력 +2, 세 번째에서 HP +20·공격력 +4를 적용한다. 보스는 기본 공격 2회 후 27 피해의 강공격을 반복하며 미리 경고한다. 적의 공격은 항상 명중한다.

일반 승리 시 아래 보상 중 하나를 선택하며 효과는 중첩된다.

| 보상 | 효과 |
| --- | --- |
| 공격 강화 | 공격력 +5 |
| 체력 강화 | 최대·현재 HP +20 |
| 도구 보급 | 회복약 +2 |

일반 적 처치는 100점, 보스 처치는 1,000점이다. 도망은 0점이며 모두 처치하면 1,300점이다.

## 6. 프로그램 구성

| 클래스 | 역할 | 주요 변수 | 주요 함수 |
| --- | --- | --- | --- |
| CApplication | 창과 실행 관리 | begin | Init, Update, Render, Destroy |
| SceneGameBegin | 화면·입력·리소스 관리 | page, battle, audio, currentBgm | Init, Update, Render, RenderBattle, PlayMusic, Destroy |
| ForestBattle | 전투·보상·진행 관리 | menu, playerHp, enemyHp, potions, score, regularCompleted | Start, Confirm, Attack, UseItem, RunAway, SelectReward, AdvanceMessage |
| GameAudio | 소리 크기 관리 | volume, ownsCom | Init, SetVolume, Destroy |

CApplication이 SceneGameBegin을, SceneGameBegin이 ForestBattle과 GameAudio를 멤버로 가진다. 화면 상태는 page, 전투 상태는 menu와 result로 관리한다. 플레이어·적·도구의 데이터는 ForestBattle 안에 둔다.

그리기는 DrawText, DrawBox, DrawBattleText, DrawSprite, DrawPreview, DrawHpBar로 나눈다. 새 도전은 ForestBattle::Start에서 초기화하고 소리·화면 설정은 유지한다. 이미지와 음악은 Init에서 불러오고 Destroy에서 해제한다.
