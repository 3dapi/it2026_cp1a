# STRIKE

# 게임 개요
장르: 턴제 타이밍 액션

개발 환경: Visual Studio / C++ / GLC2D

플레이 인원: 1인


커서가 가리키는 Gauge Bar의 위치에 따라 적을 공격하는 타이밍 액션 게임이다.


# 게임 목적
적을 처치하며 마지막에 등장하는 보스를 처치하는 것이 목적이다.


# 조작 방법
Space Bar: 공격

Esc: 일시정지, 다시시작, 게임 종료


# 게임 규칙
- 커서는 게이지의 길이만큼 좌우로 계속 왕복한다.
- Space Bar를 누른 순간의 커서 위치로 공격 판정
- 커서가 가리키는 Gauge Bar의 색상에 따라 피해량 변화
- 전투 중일 시 Space Bar 입력 인식 안함
- 적의 체력이 0이 될 시 다음 라운드 진행



# 점수/승부 규칙
플레이어가 보스를 처치하면 승리하고, 플레이어의 체력이 0이 되면 패배한다.


# 전투 규칙

## 플레이어
스페이스바를 눌렀을 때 커서의 위치에 따라 적에게 데미지를 가한다.

1. perpect (청록색 구간)
- 적에게 5의 데미지를 가한다
2. good (초록색 구간)
- 적에게 3의 데미지를 가한다
3. normal(노란색 구간)
- 적에게 1의 데미지를 가한다
4. miss(빨간색 구간)
- 적에게 0의 데미지를 가하고 적이 플레이어를 공격한다

## 적
플레이어의 공격이 끝날 시 적의 공격력만큼 플레이어에게 데미지를 가한다.

- 드래곤
-> 플레이어의 공격이 miss일 시 공격력
-> 드래곤의 hp가 특정 수치 이상 감소할 시 커서의 속도 증가

# 게임 시작 조건
시작 화면에서 게임 시작 버튼을 누르면 게임이 시작된다.


# 게임 종료 조건
- 승리 조건: 최종 보스를 처치한다.
- 패배 조건: 플레이어의 체력이 0이 된다.

게임이 종료되면 승패 여부가 표시되며, 재시작하거나 게임을 종료할 수 있다.



# 주요 게임 객체 목록

## Player
- 데이터:현재 체력, 최대 체력, 공격력, 사망여부, Gauge Bar 위치, 커서 위치
- 기능:커서 위치 별 공격력 대입, 공격, 피격, 사망
## Enemy
- 데이터:공격력, 현재 체력, 최대 체력, 사망 여부, 생성 위치
- 기능:공격, 피격, 사망
## CApplication
- ScreenState에 따라 class Scene들을 관리
## SceneGameBegin
- 게임의 메인 화면, 시작 버튼 출력
- 시작&종료 버튼 기능 및 씬 전환 요청
- 시작 : 마우스 좌클릭
## SceneGamePlay
- 게임의 플레이 화면, Gauge Bar, 커서, 적, 체력바 출력
- 필드 내의 플레이어와 적, 전투 시스템 관리
- 플레이어 공격 : Space Bar
- 게임 종료 & 게임 재시작 : Esc
## SceneGameResult
- 승/패 여부, 플레이타임, 게임 재시작&종료 출력


# 게임 화면 구성
- 시작 화면: 게임 제목, 게임 시작 버튼을 표시한다.
- 플레이 화면: 게이지바와 커서, 적, 배경, 체력을 표시한다.
- 결과 화면: 승리 또는 패배 여부, 재시작버튼과 나가기버튼, 플레이타임을 표시한다.


# 게임 진행 흐름
1. 시작 화면
2. 게임 시작 버튼 클릭
3. 플레이어와 적 초기화
4. Space Bar로 적을 공격
5. 공격 이후 적이 플레이어를 공격
6. 플레이어 또는 적의 hp = 0 이 될 때 까지 진행
7. 적이 사망 시 라운드 증가
8. 다음 라운드 적 초기화, 플레이어 데이터 조정
9. 마지막 라운드 전까지 4~8번 반복
10. 플레이어 사망 또는 마지막 라운드 클리어 시 게임 결과 화면으로 이동
11. 재시작 시 플레이어 삭제 후 3번으로 이동
12. 종료 시 플레이어 삭제 후 게임 종료
