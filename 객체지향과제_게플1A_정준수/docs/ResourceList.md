# ResourceList

본 프로젝트의 그래픽과 사운드는 과제용으로 직접 제작한 자체 리소스입니다. 외부 이미지/음원 파일을 사용하지 않았습니다.

## 이미지 리소스
| 리소스 이름 | 파일명 | 사용 목적 | 출처 | 사용 조건 |
|---|---|---|---|---|
| 배경 | background.png | 전체 게임 배경 | 직접 제작 | 과제 프로젝트 내 사용 |
| 플레이어 | player.png | 플레이어 캐릭터 | 직접 제작 | 과제 프로젝트 내 사용 |
| Target A/B | goal.png, goal_alt.png | 수집 목표 + 2프레임 애니메이션 | 직접 제작 | 과제 프로젝트 내 사용 |
| 장애물 A/B | obstacle.png, obstacle_alt.png | 낙하 장애물 + 2프레임 애니메이션 | 직접 제작 | 과제 프로젝트 내 사용 |
| 타이틀 | title.png | 시작 화면 제목 | 직접 제작 | 과제 프로젝트 내 사용 |
| 시작 안내 | start_prompt.png | 조작 및 시작 안내 | 직접 제작 | 과제 프로젝트 내 사용 |
| HUD | hud_panel.png | Score/Life/Time 표시 | 직접 제작 | 과제 프로젝트 내 사용 |
| 결과 패널 | clear_panel.png, fail_panel.png | 성공/실패 화면 | 직접 제작 | 과제 프로젝트 내 사용 |
| 숫자 | digit_0.png ~ digit_9.png | HUD 숫자 표시 | 직접 제작 | 과제 프로젝트 내 사용 |

## 사운드 리소스
| 리소스 이름 | 파일명 | 사용 목적 | 출처 | 사용 조건 |
