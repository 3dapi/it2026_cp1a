# 4주차 개발 기록

## 최종 구현
- 3주차 클래스 구조 유지 및 Game 클래스 중심으로 최종 흐름 정리
- 시작, 플레이, 성공/실패, 재시작 상태 완성
- Score / Life / Time HUD 적용
- Target 및 장애물 2프레임 애니메이션 추가
- 그래픽 리소스 전체 교체 및 실제 화면 적용
- BGM, 시작, 획득, 충돌, 성공, 실패 효과음 적용
- 결과 화면과 재시작 처리 확인
- 리소스 목록 및 README 최종 정리

- Visual Studio에서 NuGet 복원
- Debug 또는 Release 빌드
- 시작 화면에서 Enter 입력
- 좌우 이동 및 충돌 확인
- Target 획득 시 점수/효과음 확인
- 장애물 충돌 시 Life/효과음 확인
- CLEAR/FAIL 화면과 재시작 확인
- 최종 확인 후 `final` Tag 생성
