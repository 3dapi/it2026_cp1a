1. 게임 개요
- 게임명: 테트리스++
- 장르: 퍼즐
- 게임 목표: 블록을 쌓아 가로줄을 제거하고 최대한 높은 점수를 획득한다.

2. 기본 규칙
- 블록은 화면 위에서 생성된다.
- 가로 한 줄이 모두 채워지면 해당 줄이 제거된다.
- 블록이 제한선에 닿으면 게임이 종료된다.

3. 조작
- 좌우 방향키: 블록 이동
- 위 방향키: 블록 회전
- 아래 방향키: 빠르게 낙하
- 블록이 바닥에 닿은 후 일정 시간 동안 이동 및 회전 가능

4. 블록 시스템
- 블록의 종류와 색상은 랜덤으로 결정
- 기존 테트리스보다 다양한 형태의 블록 추가
- 현재 블록을 저장할 수 있는 Hold 기능 제공
- 다음 등장 블록 3개 표시

5. 점수 시스템
- 줄을 제거하면 점수 획득
- 연속으로 줄을 제거하면 추가 점수 획득

6. 난이도 시스템
- 일정 점수 이상 획득할 때마다 방해요소 추가
- 점수가 높아질수록 난이도 상승

7. 게임 종료 조건
- 쌓인 블록이 제한선에 도달하면 패배
