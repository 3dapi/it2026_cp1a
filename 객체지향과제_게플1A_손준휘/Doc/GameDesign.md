# 게임 개요 
- 롤 미드처럼 싸우는 2D 탑뷰 탄막 액션?
# 게임 목적 
상대의 HP를 0으로 만들거나, 제한 시간이 끝난 시점에서 상대보다 HP가 많을 것.
# 조작 방법 
- 이동 : 마우스 우클릭
- 공격 선택 : 마우스 휠로 전환
    - 다크소울 3, 엘든링과 유사하게
- 공격 실행 : 마우스 좌클릭
# 게임 규칙 
- 캐릭터는 우클릭 한 곳으로 다가감.
- 좌클릭 시 잠깐의 해당 방향 또는 지점에 공격 실행.
    - 공격의 실행~종료 시까지 정지 상태
# 점수/승부 규칙 
- 상대의 HP가 0이 되거나 제한시간 종료 시 상대보다 HP가 많다면 승리.
# 게임 시작 조건 
- 타이틀에서 게임 시작 누르면 3초 카운트다운 후 시작.
# 게임 종료 조건 
- 둘 중 누군가의 HP가 0이 되거나 제한시간이 종료되었을 때. 
# 플레이어 행동 
- 이동,공격.
# 적 / 장애물 / 아이템 등의 행동 
- 일단 랜덤하게 이동하다가 스킬 시전이 가능하면 바로바로 플레이어 위치에 날리도록 테스트 AI를 만들 예정.
- 플레이어가 공격 시전 시, 적절한 위치로 이동하도록 예약할 계획.
# 게임 화면 구성 
![GameSreen](Images\image02_GameLayout.png)
- 위 사진과 같이 대각선 형태의 맵

    - y축 방향으로 화면을 구성할 경우 폭이 너무 좁고 좌우가 너무 넓은 문제가 있음.

# 게임 진행 흐름
- 서로 탐색전 시작(사제용어로 니가와)
- 상대가 공격을 할 경우  
    - if (회피 성공)
        - {틈을 파고들어 반격}
    - else
        - {상대가 주도권을 잡음. 주도권을 되찾으려면 상대가 스킬을 소모하거나 틈을 노려 공격해야 함.}
- 위의 과정을 게임 종료 조건까지 반복.
# 주요 게임 객체 목록 
- 플레이어
    - 직접 조작 가능.
    - 기능상 적과 차이 없음.
- 적
    - 플레이어 캐릭터와 기능상 차이는 없음.
    - 마우스 입력 대신 임의로 이동과 공격을 하도록 AI를 짜야 함.
- 벽
    - 맵을 대각선으로 제약.
        - 벽 너머로는 이동할 수 없도록 제약해야 함.
- 서로 견제만 하면 게임이 지루해 질 것이니 슈퍼스매시브라더스의 기물 처럼 스킬 소모를 유도하거나 이동을 제약하는 등의 요소를 추가하면 좋을 듯.
# 필요한 이미지 목록 
- 대체로 그냥 도형에 색만 바꿔서 표현할 예정.
    - 비주얼 퀄리티는 낮을 것이지만, 소스를 찾는데 걸리는 시간을 단축하고, 그림 퀄리티를 일정하게 유지한다는 점을 좋게 평가했음.
# 필요한 사운드 목록
