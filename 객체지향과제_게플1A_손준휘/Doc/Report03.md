# 새 게임 기획
- 100% 오렌지 주스 처럼 공격과 수비를 번갈아 가는 주사위 배틀
- 단판전만 구현해 볼 예정.
- 공격자가 1~6 주사위를 굴리면 방어자도 1~6 주사위로 방어나 회피 가능.
    - 방어는 공격주사위 - 방어주사위 깂 만큼의 피해를 입음.
        - 단 최소 1의 대미지는 입음.
    - 회피는 회피주사위 값이 상대의 값보다 크면 대미지 0.
        - 수비에 비해 리스크가 큰 만큼 리턴을 더 강화시킬 필요가 있을 듯?
- 각자의 체력은 20 정도로 생각해 놓고 있음.
