# 기본 구현 요소
- 이동 시스템
    - 우클릭하면 그곳으로 직진.
        - 길 찾기는 난이도가 매우 높으니 장애물은 구현하지 않을 것.
- 적
    - 플레이어 캐릭터와 같은 사양.
        - 다만 이동 위치는 마우스 위치로 얻는게 아니라 임의로 지정된 위치로 가도록 조금만 변형하도록 하는 등. 범용적인 코딩이 목표.
 
 # 추가 요소
 - 난입
    - 랜덤 이벤트로 적/아군 정글러가 개입하도록 하면 게임에 변수가 늘어나 더 재미있어지지 않을까 생각됨.
- 미니언
    - 일대일까지 구현해보고 여유가 된다면 CS 먹기 모드 같은 것도 만들어 보는 것이 어떨까 생각함.
- 스킬
    - 벡스 Q같은 투사체, 벡스E 같은 범위기, 오리아나 은구슬 같은 스킬을 생각하고 있음.
- AI 회피 위치
    - 투사체는 이론상 투사체의 궤도와 수직으로 피하는 것이 적절하지만 이건 내적 같은 어려운 연산이 많이 들어갈 것 같으니 그냥 플레이어 에임에 맡기는 걸로.
    - 범위기는 시전 위치와 반대 방향으로 이동하게. 범위기 선딜이 끝나기 전까지.
        - (시전 위치 - 자신 위치) * n 지점으로 이동하게 하기.
            - 만약 해당 좌표가 범위 내일 경우 n을 늘려서 다시 연산.
                - maxCount 까지 해도 사거리 내라고 판단될 경우 (자신 위치 - 시전 위치) * n으로 이동.
    - 오리아나 기술 같은 거는 이동할 위치가 피격 범위 내라면 거기로 이동하지 않기 하는 걸로.
    - 일단 임시 코드로 적당히 랜덤으로 움직이게 하는 코드를 만들어야 할 듯.
