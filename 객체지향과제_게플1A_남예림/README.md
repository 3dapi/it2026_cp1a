## 게임 소개

「징검다리」는 가위바위보와 위치 이동 시스템을 결합한 1:1 캐주얼 전략 대전 게임이다. 플레이어(영희)와 컴퓨터(철수)는 총 11개 지점(0번 ~ 10번)의 징검다리 위에서 하나의 지우개 말을 두고 대결하며, 말은 징검다리 정중앙인 5번 지점에서 시작한다. 매 턴 가위바위보 결과에 따라 말이 앞뒤로 이동하고, 징검다리 끝 지점(0번 또는 10번)으로 밀려나는 쪽이 패배한다. 단순한 가위바위보의 확률 싸움을 넘어, 끝 지점으로 밀어내는 위치 선점과 예측 심리전이 핵심이다.

## 게임 기본 정보

* **게임 제목:** 징검다리

* **장르:** 캐주얼 전략

* **플레이 방식:** 1:1 턴제 대전 (Player vs Computer)

* **핵심 목표:** 가위바위보 승패를 이용해 지우개 말을 징검다리 끝 지점(0번 또는 10번)으로 밀어내기

* **시작 위치:** 징검다리 정중앙 (단일 말이 5번 지점에서 시작)

* **조작 수단:** 마우스 클릭 및 키보드 단축키 (1: 가위, 2: 바위, 3: 보)

## 핵심 재미

* 어린 시절 책상 위 지우개 싸움과 징검다리 놀이의 감성을 현대적 캐주얼 게임으로 재해석.

* 매 턴의 승패가 연속적인 위치 변화로 누적되어 상대의 패턴을 읽고 수를 두는 즐거움 제공.

* C++ 난수 생성기 기반의 컴퓨터 선택에 맞춰 상황별 대응 방안을 판단하는 재미.

* 징검다리 끝으로 몰릴수록 높아지는 손에 땀을 쥐는 긴장감과 위치 선점 심리전.

* 턴 승패 프로필 연출과 WIN/LOSE 화면, 결과 일러스트까지 이어지는 유쾌한 승부 연출.

## 게임 진행 흐름

1. 메인 메뉴(`SceneGameBegin`)에서 마우스 클릭으로 [게임 시작]을 선택한다. [게임 방법] 클릭 시 룰 설명 팝업이 표시된다.

2. 인게임(`SceneGamePlay`)이 시작되면 총 11개 지점의 징검다리 중앙(5번)에 지우개 말이 배치되고 인게임 BGM이 재생된다.

3. 하단 UI의 [가위], [바위], [보] 버튼을 마우스로 클릭하거나 숫자키(1, 2, 3)를 입력해 카드를 제출한다.

4. 선택 완료 시 3 → 2 → 1 카운트다운(1초 간격, 효과음 동반)이 진행되고, 3초 후 C++ 난수 함수로 산출된 컴퓨터의 카드가 공개된다.

5. 공개 1.2초 후 승패 판정이 이루어지며, 턴 결과에 따라 승패 프로필 연출과 함께 말이 이동한다. (플레이어 승리 시 +1, 패배 시 −1, 무승부 시 제자리)

6. 말이 징검다리 끝 지점(0번 또는 10번)에 도달하면 게임오버가 되고, WIN/LOSE 전체화면 연출이 표시된다.

7. 연출 1초 후 엔딩 버튼이 나타나고, 클릭하면 결과 화면(`SceneGameResult`)으로 전환된다.

8. 결과 화면에서는 최종 승자에 따른 일러스트와 엔딩 사운드가 출력되고, 1초 후 돌아가기 버튼이 표시된다. 버튼 클릭 또는 Enter 입력 시 게임 데이터를 초기화하고 메인 메뉴로 복귀한다.

## 규칙 및 시스템 명세

* **화면 해상도:** 800 × 600 (4:3 비율, glc2d 렌더링 기준)

* **징검다리 구성:** 일직선 상의 총 11개 지점 (0번 ~ 10번), 양 끝(0번, 10번)은 아웃 지점

* **초기 배치:** 지우개 말 1개가 5번 지점(중앙)에서 시작

* **컴퓨터 패 결정:** C++ 난수 생성기(`rand()`)를 이용해 0 ~ 2 (가위/바위/보) 균등 무작위 추첨

* **이동 규칙:** 플레이어(영희) 승리 시 오른쪽 1칸(+1), 패배 시 왼쪽 1칸(−1), 무승부 시 이동 없음

* **턴 타임라인:** 카운트다운 3초 → 컴퓨터 카드 공개 1.2초 → 승패 프로필 및 말 이동 1.2초 (실시간 기반, 총 5.4초)

* **종료(아웃) 조건:** 말이 0번 또는 10번 지점에 도달하면 게임오버 판정

## 화면 구성

* **MAIN MENU (`SceneGameBegin`):** 책상 위 도화지 배경, '징검다리' 캘리그라피 로고, [게임 시작], [게임 방법], [나가기] 버튼 (호버 이미지 전환), 게임 방법 팝업

* **IN GAME (`SceneGamePlay`):** 클로즈업된 도화지 징검다리(11개 지점), 영희/철수 프로필, 지우개 말 배치, 하단 가위/바위/보 카드 버튼, 중앙 카운트다운·컴퓨터 카드·턴 승패 프로필 연출, WIN/LOSE 종료 연출 및 엔딩 버튼

* **RESULT (`SceneGameResult`):** 최종 승패 일러스트(영희 승: 아이스크림 사주는 영희 / 철수 승: 가방 메고 울상 짓는 철수), 돌아가기 버튼 (호버 이미지 전환)

## 객체지향 클래스 구조 설계

* `CApplication`: 메인 윈도우 생성, 프레임 루프 관리 및 씬(Scene) 전환 총괄. `ChangeScene()`에서 씬 전환, 게임 재시작 시 `ResetGame()`, 결과 진입 시 `SetPlayerWin()` 호출

* `SceneGameBegin` / `SceneGamePlay` / `SceneGameResult`: 각 씬별 리소스 관리, 사용자 입력 처리, 게임 상태 제어 및 렌더링. `Update()`의 반환값(-1 종료 / 0 메인 / 1 플레이 / 2 결과)으로 씬 전환을 요청한다.

* `SceneGamePlay`: 턴 타임라인 진행과 가위바위보 판정을 직접 수행. `StartTurn()`(카운트다운 시작), `FinishTurn()`(난수 기반 승패 판정 및 말 이동), `GetPlayerWin()`(결과 씬에 승패 전달)

* `Piece`: 징검다리 위 지우개 말의 논리 객체. 위치 인덱스 관리 전담(렌더링 없음), `Init()`, `Reset()`, `Move()`, `GetPosition()`

## 빌드 및 실행 방법

1. 저장소를 Clone한 뒤 `26085007-NamYerim-VN.sln`을 Visual Studio 2022에서 연다.

2. 빌드 시 NuGet 패키지(glc2d, Microsoft.DXSDK.D3DX)가 자동으로 복원된다.
